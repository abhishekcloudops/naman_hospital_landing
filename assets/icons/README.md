# Icon sources

- Medical and service SVGs in `health/` are from [Health Icons](https://healthicons.org/) and are available under CC0/public domain.
- `whatsapp.svg` is the WhatsApp glyph from [Bootstrap Icons](https://icons.getbootstrap.com/icons/whatsapp/) under the MIT License. It is displayed in WhatsApp green (`#25D366`) and paired with a visible text label.

The SVGs are stored locally so the website does not depend on a third-party icon CDN at runtime.
